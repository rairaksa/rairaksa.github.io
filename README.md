# Rai Raksa Muhamad — Personal Portfolio (`rairaksa.github.io`)

Personal portfolio and resume web application for **Rai Raksa Muhamad** (Backend Engineer), built with **React 19**, **Vite 6**, **TailwindCSS 3**, and **Swiper**.

- **Live Website:** [https://rairaksa.github.io](https://rairaksa.github.io)
- **Downloadable Resume (ATS PDF):** [`/file/cv.pdf`](https://rairaksa.github.io/file/cv.pdf)

---

## Features

- **Dark / Light Theme Toggle** with `localStorage` persistence.
- **Hero & CTA Actions:** Direct **Download CV** (`./file/cv.pdf`) and **Contact Me** links plus LinkedIn & GitHub profiles.
- **Categorized Skills & Experience Timeline:** Highlighting Go (Golang) microservices, PHP/Laravel, PostgreSQL, MySQL, Redis, AWS (SNS, SQS, S3), Grafana observability, n8n workflow automation, and AI-assisted engineering.
- **Filterable Portfolio Showcase:**
  - Filter by **All Projects**, **Company / Enterprise**, or **Freelance & Independent**.
  - Switch between **Slide (Carousel)** and **List All** views.
- **SEO & Open Graph Meta Tags** configured for LinkedIn, WhatsApp, and X/Twitter previews.

---

## Tech Stack

- **Frontend:** React 19, Vite 6, TailwindCSS 3, Swiper 11
- **Testing:** Vitest, React Testing Library, JSDOM
- **Deployment:** GitHub Pages (`gh-pages`) & Nginx static hosting

---

## Development & Build Commands

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run unit tests
npm test

# Build production bundle to ./build
npm run build

# Deploy ./build to GitHub Pages (gh-pages branch)
npm run deploy
```
